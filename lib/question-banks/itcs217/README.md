# ITCS217 preset question imports

Source: `ITCS217_quiz_variations_86.zip`, `quiz_variations_86.json` (86 questions).

- `lecture-9/variations.ts`: 38 questions from IDs beginning `L9-`.
- `lecture-10/variations.ts`: 48 questions from IDs beginning `L10-`.
- Each lecture has Part 1 and Part 2, with separate A/B variation presets.
- Subject names are normalized to `ITCS217_Computer Data Communication`. Lecture labels are derived from IDs, and topics are prefixed with the lecture label. Prompts, IDs, answers, correct indexes, explanations, option explanations, source references, provisional objectives, versions, tags, and draft status are retained.
- The existing 30-question Lecture 9 bank remains available as its own preset.

The source marks all 86 questions as draft and reports generator checks, not independent validation. Importing them for this guest MVP does not promote them to approved questions or create mastery evidence. Referenced lecture PDFs are not included in this archive.

The variation source files are retained for reference but excluded from the active bank and folder library. The subject-folder MVP uses the original 30 questions as its test quiz.
