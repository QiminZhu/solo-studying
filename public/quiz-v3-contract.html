Six-format bank import guide

Import a JSON array compatible with Quiz Master BankQuestion v3. Download the labeled software fixture example. It is not approved lecture content.

Common fields

Every question requires id, version, subject, topic, objectiveId, type, difficulty, cognitiveLevel, prompt, explanation, sourceRefs, and status. Optional objectiveIds must include the primary objectiveId. Source references use actual file names and positive 1-based page numbers; never invent citations.

Format keys

  • single, multiple, boolean: answers, correct zero-based indexes, and optionExplanations for every option. Select-all needs at least two correct and one incorrect option. Boolean answers are exactly True and False.
  • matching: leftItems, rightItems, reuseRight (default false), matches as [leftIndex, rightIndex] pairs, and pairExplanations aligned with matches. State reuse in the prompt when enabled.
  • ordering: shuffled items, correctOrder as a complete permutation of indexes, and stepExplanations in keyed position order.
  • fill_blank: sequential prompt markers {{1}}, {{2}}, etc., and blanks with matching IDs. Text blanks need acceptedAnswers, caseSensitive, trim, collapseWhitespace, explanation. Numeric blanks need value, finite nonnegative absoluteTolerance, unit, rounding, explanation; state units and rounding in the prompt.

Authoring policy

Default maximums per quiz: 20 questions and 50 response units; per question: 4 matching pairs, 6 ordering items, 3 blanks, 6 choice options. These are configurable workload policies, not learning thresholds.

A single/boolean response counts as one unit; select-all counts every option; matching counts every pair; ordering counts every position; blanks count every blank. Excess workload blocks saving the author preview and must be split or explicitly revised by the author.

Import and publication

Files must be valid JSON arrays smaller than 1 MB. The importer preserves content and reports malformed data with field paths. Imports are always unverified author previews, even if their supplied status says approved.

Publishing Lecture 9 requires complete original source, an independently approved objective catalog, a coverage blueprint, independent validation of exact final question versions, and a successful source-bound coverage/workload gate. No Lecture 9 bank is published by this importer.

Scoring and saved attempts

Each question earns one point only when its complete answer matches. Multipart feedback is diagnostic and adds no extra question weight. First checks are preserved separately from retries. Deferred quizzes reveal feedback after final submission only. Saved attempts stay in this browser and do not synchronize across devices. Repeated success is practice progress, not proof of lecture mastery.
